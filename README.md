## 1. 專案重大轉型與規格 (v2.0)

### 1.1 架構革新重點
1. **取消固定難度階級**：不再使用初階、中階、魔王組的固定關卡。
2. **升級為「五大洲分區命題」**：進入遊戲前，由特工自行選擇欲前往查驗的「大洲分區」，也可選擇「全球特工總挑戰」。
3. **動態亂數出題引擎**：
   - 每輪挑戰由該洲題庫池中**依亂數動態抽選 5 道題目**，每次挑戰題目完全不同！
   - 每題 1 個目標國＋2 個該洲別隨機混淆選項（3 選 1），選項順序隨機洗牌。
4. **純國旗視覺盲測**：
   - 選項卡片全面清除國名與 ISO 代碼，迫使學生真正運用肉眼觀察顏色、長寬比（保持真實比例不裁切）、圖騰與條紋。
5. **即時雙向教學回饋**：
   - **答對**：觸發 APPROVED 放行鋼印，揭曉該國國名與地理背景。
   - **答錯**：觸發 SECURITY ALERT 警報對照，同時展示該題 3 面國旗各自的國名與關鍵差異點，落實立即訂正。
6. **通關結算複習**：
   - 結算畫面自動彙整「本輪 5 道隨機題目的鑑旗特工速記筆記」，方便學生課堂回顧。
